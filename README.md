# dsh-plugins

DSH（DeepSeek Harness）插件单仓。

| 插件 | 说明 | 目录 |
|---|---|---|
| **统筹项目与规则** / Project & Rules Steward | 把一句话的要求做成可核对的规则卡并写进对应的 `AGENTS.md`，兼管规则台账、跨文件检索、项目档案、计划、交接、改动账本与时间线 | [`plugins/steward`](plugins/steward) · [English](plugins/steward/README.en.md) |

## 安装

```bash
dsh plugin add dsh-plugin-steward
```
