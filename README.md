# dsh-plugins

DSH（DeepSeek Harness）插件单仓。

| 插件 | 说明 | 目录 |
|---|---|---|
| **规则与计划** / Rules & Plans | 把一句话的要求做成可核对的规则卡并写进对应的 `AGENTS.md`，兼管规则台账、跨文件检索、项目计划与时间线 | [`plugins/koujing`](plugins/koujing) · [English](plugins/koujing/README.en.md) |

## 安装

```bash
dsh plugin add dsh-plugin-koujing
```
